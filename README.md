# data-analytics-ab-testing
Мой опыт в аналитике данных, оценка результатов AB теста. Целью работы было провести анализ результов A/B-теста, чтобы принять обоснованное решение о смене маркетинговой механики. Клиенты были разбиты на две группы одинакового размера случайным образом. Были исследованы две таргет-метрики: конверсия из рекламы в покупку и средний чек покупки. 

Аналитические компетенции:
- Разведочный анализ данных, предобработка
- Обоснованный выбор статистической обработки результатов А/Б-тестов.
- Сегментация результатов АБ-теста по городам
- Оценка статистической значимости тестов
- Моделирование результатов АБ-теста.

Инструменты и приёмы работы с Python:
- Использование библиотек pandas, numpy, matplotlib, seaborn, scipy.stats для анализа и визуализации данных.
- Очистка и предобработка данных: проверка пропусков, фильтрация, преобразование типов.
- Объединение таблиц.
- Агрегация и группировка данных.
- Создание функций для автоматизации аналитических расчётов.
- Построение графиков.
- Выгрузка данных в excel.
